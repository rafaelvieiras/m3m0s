# D5 — Name: M3m0s (was "Engram" until 15 Jul 2026)

**Status:** Accepted

**Decision:** the project, initially named "Engram" (the physical trace of a memory, in neuroscience), was **renamed to "M3m0s"** on the same day.

**Why:** a real product called Engram already exists — **getengram.app**, a SaaS for agent conversation memory (Cloudflare Workers/[D1](D1-existing-memory-layers-stay-separate.md)/Vectorize, native MCP, paid plans). That is a direct name collision with a product in the same problem space; the name was changed before any publication. M3m0s is not related to getengram.app. A full analysis of that competitor/reference is in [D6](D6-getengram-analysis.md) — worth reading before implementing Phase 1, since it contains concrete features to borrow.
