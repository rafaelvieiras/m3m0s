# A6 — Embeddings provider

**Status:** Closed (16 Jul 2026)

**Confirmed as the interim default on 15 Jul 2026:** keep OpenAI (`text-embedding-3-small`, already validated) until Phase 4, avoiding the risk of search quality dropping without prior validation of an alternative.

**Closed on 16 Jul 2026:** the maintainer decided not to migrate to local Ollama — there is no habit of operating Ollama day to day, and the OpenAI default is already simple enough for anyone to configure in the future (it only needs an API key, with no extra local infrastructure running alongside M3m0s). OpenAI (`text-embedding-3-small`) stays definitive, not just interim; do not reopen without a new explicit reason from the maintainer.
